## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `poster.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png` and verifies the output: a valid PNG,
exactly 1024×576, at most 1 MiB.
